# Responsive Portfolio & Task Management Web App

Fully responsive front-end portfolio website and task manager built from scratch using pure HTML5, CSS3, and Vanilla JavaScript for UNIMAS web development coursework.

## 📂 Files Included
* **`index.html`** - Main portfolio markup structure and sections.
* **`style.css`** - Custom responsive stylesheet utilizing Grid and Flexbox.
* **`script.js`** - Vanilla JavaScript logic featuring 10 interactive elements, form validation, and modals.
* **`Main.java` & `TaskManager.java`** - Java simulation classes for backend task management logic.
